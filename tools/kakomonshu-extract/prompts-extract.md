あなたは、行政書士試験の市販過去問集(1問1答形式)のページ画像を、構造を保ったJSONへ書き起こす担当です。

## 入力
- 対象ページ(書籍PDFのページ番号、1始まり): {PAGE_START}〜{PAGE_END}
- 各ページは次の画像ファイルになっている。**Readツールで、これらを上から順にすべて読む**(他のファイルは読まない):
{IMAGE_LIST}

## 出力
**JSONオブジェクト1つだけ**を出力する(前後の説明文・コードフェンスは不要)。形式は次のとおり。

{
  "pdf_pages": [{PAGE_START}, {PAGE_END}],
  "blocks": [ ... 紙面の読み順に並べた要素 ... ]
}

blocksの要素は3種類。

1. 見出し
   {"type":"heading","level":1,"text":"憲法","pdf_page":12}
   - level: 1=科目(「I.憲法」など) / 2=章(番号なしの見出し。例「人権」「国会」) / 3=節(「3 精神的自由権」のように数字+空白) /
     4=項(「1)思想・良心の自由」のように数字+閉じ括弧) / 5=「①…」。**番号の書式どおりに付け、ページごとに変えない。**
   - 見出しの文字は紙面のまま書く(番号も含める)。
2. 肢(1問1答の1つの記述)
   {"type":"item","pdf_page_q":12,"pdf_page_a":13,"rank":"B","exam_refs":["H24-8-1","R3-8-1"],
    "original":false,"stmt_no":1,"question_text":"…","answer":"×","explanation_text":"…",
    "confidence":"high","uncertain":[{"field":"question_text","reason":"下線部がかすれて判読不能"}]}
   - rank: 「A □□□」「B □□□」「C □□□」のA/B/C。
   - exam_refs: 肢の上の括弧書き(出題履歴)を1つずつ配列に。書いてあるとおりに転記(「R元」「H元」「·」等もそのまま)。
   - original: 「(オリジナル)」と書かれていれば true。
   - stmt_no: 肢の番号(整数)。番号が紙面にない場合は null。
   - answer: 解説ページの「○」または「×」(OCRでは O / x のことがある)。対応する記載が見つからなければ null。
   - 問題文と解説は別ページに分かれていることが多い。**番号とページの並びから対応づけ**、pdf_page_q(問題側)とpdf_page_a(解説側)を記録する。
     このページ範囲内で対応先が見つからない肢は、answerとexplanation_textをnullにして、uncertainに {"field":"answer","reason":"解説ページが範囲外"} を入れる。
   - confidence: 全文字を確信をもって読めたら high、一部不確かなら medium、複数箇所が不確かなら low。
3. その他
   {"type":"other","kind":"toc|preface|column|table|figure|note","text":"…","pdf_page":10}
   - 目次・コラム・表・図・欄外の注記など。表は行ごとに " | " 区切りで text に入れてよい。

## 転記ルール(厳守)
- **見たとおりに転記する。意味を推測して補完・修正・要約・言い換えをしない。** 原本の誤植もそのまま写す。
- 読めない文字は「〓」1字に置き換える(推測で埋めない)。その箇所を uncertain に必ず記録する。
- 下線が引かれた語句は <u>…</u> で囲む。太字は <b>…</b> で囲む。
- 日本語の常用漢字・かな・カナで書く。簡体字・繁体字・ハングル・英字の疑似文字を出力しない(紙面が日本語であるのに中国語の字形に見える文字は、日本語の字形に直して転記する)。
- 条文番号・年号の数字は紙面のまま(全角/半角を変換しない)。
- ヘッダー・フッター・ページ番号・「テキストp.○○」のような参照欄は、blocksに入れず無視する。ただしページ番号は pdf_page の確認に使ってよい。
- 紙面の端で文字が切れて見える場合は、**見えている文字だけを書き、欠けた文字を推測で補わない**。
  **文字が欠けている行の行末(または欠けている位置)には、必ず「〓」を1つ置く。**「〓」を省いて前後をつなげてはならない
  (後工程で、欠けた位置を特定して別の資料で補うために必要)。欠けた文字数は推測せず、1か所につき「〓」は1つ。
  同じ肢で複数の行が欠けていれば、行ごとに「〓」を置く。欠けた箇所は uncertain にも記録する。
- ページの途中で始まる/終わる肢は、見えている範囲だけを記録し、欠けている項目は null とし uncertain に理由を書く(次の範囲で取り直す)。
- 1ページに複数段組みがある場合は、左→右、上→下の読み順にする。
