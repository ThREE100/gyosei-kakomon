# note記事コンテンツ（行政書士試験 過去問解説）

行政書士試験の過去問について、年度・問題ごとの解説記事とインフォグラフィック生成プロンプトをまとめる場所。

姉妹プロジェクト [`ThREE100/chosashi-app`](https://github.com/ThREE100/chosashi-app)（土地家屋調査士試験）の
`note-articles/` で確立済みの構成・執筆ルールを踏襲しつつ、行政書士試験の出題形式（択一式・多肢選択式・記述式が
1回の試験に混在する／科目が基礎法学〜一般知識等まで幅広い）に合わせて調整している。詳細は
[`article-template.md`](./article-template.md) を参照。

## フォルダ構成（予定）

```
note-articles/
├── README.md                   このファイル
├── article-template.md         記事・インフォグラフィックプロンプトのテンプレート（出題形式別に3種）
├── r7-mondai/                  令和7年度・問題ごとの記事（q02-xxxx.md 〜 q57-xxxx.md）
│   └── 00-index.md             令和7年度の全56問の出題リスト（構成固め用のロードマップ）
├── r6-mondai/ …                （今後、年度をさかのぼって追加）
├── laws/                       （今後）条文・判例の検証済みローカル参照データ（chosashi-appのlaws/相当）
├── link-map/                   （今後）年度別・記事間の相互リンク表
└── topics/                     （今後）分野横断のテーマ別まとめ記事（頻出論点の早見表など）
```

## データソース

- 問題文：公式PDF（行政書士試験研究センター `rX_mondai.pdf`）。**問題1・58〜60は著作権の都合によりPDF自体に
  掲載されていない**（令和7年度で確認済み。他年度も同様の欠番がある前提で都度確認する）。
- 正解：このアプリのデータセット `data/exam.json`（公式正解HTML `rXans.html` を解析済み。年度は `year` フィールドが
  `"R7"` 等の形式）。年度・問題番号でフィルタすれば当該年度の全問（択一・多肢選択・記述の別、科目、選択肢、正解）が
  揃う。
- 記述式（問44〜46相当）は `data/exam.json` 上 `answer: null`（公式模範解答が非公開のため）。記事では判例・条文に
  基づく参考解答として扱い、公式模範解答ではない旨を明記する（詳細は `article-template.md`）。
- 参考：`gyosei-shiken.or.jp`（行政書士試験研究センター公式サイト）は、このクラウド実行環境のネットワークポリシーで
  直接アクセスがブロックされている。正解の再確認が必要な場合は、環境のネットワーク設定でこのホストを許可するか、
  ローカル環境で確認する。
