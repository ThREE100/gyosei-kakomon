# note記事コンテンツ（行政書士試験 過去問解説）

行政書士試験の過去問について、年度・問題ごとの解説記事とインフォグラフィック生成プロンプトをまとめる場所。

姉妹プロジェクト [`ThREE100/chosashi-app`](https://github.com/ThREE100/chosashi-app)（土地家屋調査士試験）の
`note-articles/` で確立済みの構成・執筆ルールを踏襲しつつ、行政書士試験の出題形式（択一式・多肢選択式・記述式が
1回の試験に混在する／科目が基礎法学〜一般知識等まで幅広い）に合わせて調整している。詳細は
[`article-template.md`](./article-template.md) を参照。

## フォルダ構成（予定）

```
note-articles/
├── README.md                   このファイル
├── article-template.md         記事・インフォグラフィックプロンプトのテンプレート（出題形式別に3種）
├── qa-checklist.md              記事作成後のダブルチェック指示書（正解照合・条文突き合わせ・初学者向け確認等）
├── r7-mondai/                  令和7年度・問題ごとの記事（q02-xxxx.md 〜 q57-xxxx.md）
│   └── 00-index.md             令和7年度の全56問の出題リスト（構成固め用のロードマップ）
├── r6-mondai/ …                （今後、年度をさかのぼって追加）
├── laws/                       （今後）条文・判例の検証済みローカル参照データ（chosashi-appのlaws/相当）
├── link-map/                   （今後）年度別・記事間の相互リンク表
└── topics/                     （今後）分野横断のテーマ別まとめ記事（頻出論点の早見表など）
```

## データソース

- 問題文：公式PDF（行政書士試験研究センター `rX_mondai.pdf`）。**問題1・58〜60は著作権の都合によりPDF自体に
  掲載されていない**（令和7年度で確認済み。他年度も同様の欠番がある前提で都度確認する）。
- 正解：このアプリのデータセット `data/exam.json`（公式正解HTML `rXans.html` を解析済み。年度は `year` フィールドが
  `"R7"` 等の形式）。年度・問題番号でフィルタすれば当該年度の全問（択一・多肢選択・記述の別、科目、選択肢、正解）が
  揃う。
- **記述式（問44〜46相当）にも公式の正解例がある**（訂正：当初「公式模範解答が非公開」としていたが誤り）。
  `rXans.html`には「記述式問題の正解例」タブがあり、40字程度の公式正解例が公表されている。`data/exam.json`の
  `answer: null`は、このアプリのデータセットが正解例のテキストを未収録なだけ。記事では公式正解例をそのまま
  引用する（詳細は `article-template.md`）。
- 参考：`gyosei-shiken.or.jp`（行政書士試験研究センター公式サイト）は、このクラウド実行環境のネットワークポリシーで
  直接アクセスがブロックされている。正解の再確認が必要な場合は、環境のネットワーク設定でこのホストを許可するか、
  該当ページ（PDF・HTML）を会話にアップロードしてもらう。
- **令和7年度・検証済み（2026-09-24）**：著者からアップロードされた公式ソース4点（`r7_mondai.pdf`本文と同一の
  ハッシュ値のPDF、`r7ans.html`〈択一60問の正解＋記述式3問の正解例〉、年度横断の正解DB `answers.json`〈R2〜R7〉、
  年度横断の問題文パース結果 `questions_parsed.json`〈R2〜R7、問1・58〜60は`"type":"omitted"`で明示〉）を、
  このリポジトリの`data/exam.json`と突き合わせた。**令和7年度の56問すべてで正解が完全一致**（択一・多肢選択とも
  不一致ゼロ）。問1・58〜60は、正解番号（1＝③、58＝④、59＝④、60＝①）は公式サイトで分かるが、問題文自体が
  非掲載のため、論点解説記事は作成できない（正解だけ紹介しても学習価値が薄いため、当面はロードマップ56問から
  除外する方針を維持）。

## 参考資料の利用について（2026-09-24合意）

ローカルPC（`C:\Users\m2100\...\行政書士試験_アプリ開発`）に、著者が別途用意した学習コンテンツ（解説教材等）が
ある。これを解説記事の執筆に使う場合は、次の制約を厳守する。

- **利用してよい範囲**：解答・正解番号の確認、論点の当たりづけ（どの条文・判例が問題になっているかの参考）まで。
- **禁止**：教材の解説文・言い回しをそのまま、または軽微な言い換えで転記すること。条文・判例に基づき、このリポジトリ
  （または一次情報＝e-Gov法令検索・裁判所判例検索）で確認し直した上で、自分の言葉で解説を書く。
- 上記の学習コンテンツはこのクラウド実行環境からは参照できない（ローカルPC上のファイルのため）。参照する必要が
  生じた場合は、該当ファイルを会話にアップロードしてもらうか、リポジトリ化されていればそのリポジトリ名を教えて
  もらって追加する。
- **2026-09-24追記**：著者から、当該フォルダ由来と見られる一問一答形式のデータ（`questions.json`／
  `questions_cleaned.md`、全2163問、`data/oneliner.json`と同一スキーマ＝`question`/`answer`/`explanation`
  を含む）がアップロードされた。これも上記と同じ制約の対象——論点の当たりづけ・重複出題の確認には使えるが、
  `explanation`フィールドの文章をnote記事にそのまま転記・軽微な言い換えで流用することは禁止。

## 記事のダブルチェック

問題作成が一区切りついた段階で、[`qa-checklist.md`](./qa-checklist.md) に従って記事をダブルチェックする。
正解の照合、条文原文との突き合わせ、解説の論理性、初学者向けの分かりやすさ、インフォグラフィックプロンプト
の正確性を確認する固定の指示書で、2026-09-24〜25に令和7年度 問2〜問20を実際にチェックした際に見つかった
問題の実例も記録している。
