# 令和元年度 出題リスト（構成固め用ロードマップ）

全60問中、著作権の都合で**問題1・20・58〜60は公式PDFに問題文が掲載されていない**（他年度と同様の
パターンだが、令和元年度は問1・58〜60に加えて**問20が非掲載**である点が令和2〜4・7年度＝問1・58〜60の
4問除外、令和3年度＝問7追加除外、令和2年度＝問5追加除外、とは異なる独自パターン）。

さらに、**問28は出題ミス等により「全員正解」の措置がとられている**（著者が貼り付けた公式正解表に
「問題２８　全員正解」と明記）。単一の正解を前提とした通常の解説記事が書けないため、著作権による
非掲載とは別の理由でロードマップから除外する。

以上、**除外6問（問1・20・28・58〜60）**を除く、実際に記事化できる**54問**の一覧が以下。

**重要な違い（データソース）**：令和2〜7年度と異なり、**令和元年度はこのアプリの`data/exam.json`に
収録されていない**（`data/exam.json`はR2〜R7のみを収録）。したがって、正解の確認は他年度のような
`data/exam.json`との機械的な突合ができず、著者がアップロードした公式PDF（`r1_mondai.pdf`）本文と、
著者が会話に直接貼り付けた公式正解表（択一式60問の正解＋記述式3問の正解例）を直接照合する方法に
よる。将来`data/exam.json`にR1データが追加された場合は、あらためて機械的な突合を行うことが望ましい。

形式の記号：**択一式A**＝ア〜オ等の記述（または下線を引いた用語）の正誤の組合せを選ぶ形式（出題形式A
テンプレート）／**択一式A（変則）**＝空欄への語句の組合せ、または対応表形式を1〜5から選ぶ形式（問21・
48・54が該当）／**択一式B**＝1〜5の記述から正しいもの・妥当なもの・誤っているものを選ぶ単純5択形式
（出題形式Bテンプレート）／**多肢選択式**＝空欄ア〜エに語句をあてはめる形式（出題形式C、問41〜43）／
**記述式**＝40字程度で記述する形式・公式正解例あり（出題形式D、問44〜46）。
