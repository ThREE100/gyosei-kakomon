# 必要な法令・条文リスト（最新版チェック用）

note記事の法的根拠を最新の条文で検証するため、著者からチャットに貼ってもらう法令の優先順位付きリスト。
貼られたテキストは、chosashi-appの `laws/` 相当（このリポジトリでは `note-articles/laws/`）にファイル化して
保存する。全文でなくとも、e-Gov法令検索の最新施行日時点のものであれば抜粋でも可。

**貼り付け時の注意（2026-09-24判明・解消済み）**：チャットへのコピー＆ペーストでは、e-Gov法令検索が条文中の
他法令への参照を自動展開し、無関係な法令が大量に混入することがある（憲法のケースで発生）。**e-Govの法令
ページをHTMLファイルとして保存してアップロードする方式なら、この問題は起きない**（民法・商法・会社法で確認
済み）。今後もこの方式（法令ページを保存 → アップロード）を推奨する。
