# 過去問集(TAC出版「合格革命 行政書士 分野別過去問集 2026年度版」)取り込みメモ

2026-09-30に、著者から会話にアップロードされた市販書籍のOCRテキスト(Markdown、約1.7MB)を取り込んだ記録。

## 保存方針(2026-09-30合意)

本書は市販書籍であり、このリポジトリは**公開(public)**のため、**OCR全文・出版社の解説文はコミットしない**。

| 置くもの | 置かないもの |
|---|---|
| `index.json`:肢ごとの出典メタ情報(科目・節見出し・ランクA/B/C・出題履歴ID・肢番号・原本の行番号) | OCR全文、肢の本文(問題文)、出版社の解説文 |
| 本READMEの取り込み統計 | 解説文の転記・軽微な言い換え(`README.md`「参考資料の利用について」の既存ルールと同じ) |

- 原本(OCR全文)は著者のローカルPCにあるファイルが正本。取り込み時のSHA-256は
  `aa677cda0e82dafc90d8766c0b1cbf6a8bb7b37c59f7135b93fa2b0e9f6b71b6`(将来、同じファイルか照合するため)。
- 非公開リポジトリへの全文保存は、この環境のGitHub権限では新規リポジトリを作成できなかった(403)ため未実施。
  非公開リポジトリを用意すれば、全文をそこへ置ける。
- 肢の本文・正誤・解説が必要な作業は、次のどれかで行う:①既存の`data/oneliner.json`(2163問・同系統データ、
  `year_codes`/`difficulty`/`answer`あり)、②`data/exam.json`(本試験形式)、③その都度、原本を会話にアップロード。
  図解プロンプト用の文言は、いずれの場合も条文・判例から**自分の言葉で**書き起こす。

## `index.json` の内容と精度

機械的に抽出したメタ情報のみ。各要素:

| キー | 内容 |
|---|---|
| `seq` | 原本での登場順の通し番号 |
| `subject` | 科目(原本の見出し。OCRの「素法」は「憲法」に補正) |
| `section` | 直近2つの見出し(章・節)。OCRの取りこぼしで前後の節が混ざることがある |
| `rank` | 原本のA/B/Cランク(A=最重要) |
| `exam_refs` | 出題履歴ID(例 `H24-8-1`=平成24年度 問8 肢1、`H19-48-オ`=平成19年度 問48 肢オ、`R元`=令和元年) |
| `original` | 原本が「オリジナル問題」(過去問ではない)と表記している場合`true` |
| `stmt_no` | 原本内の肢番号(検出できなかった場合`null`) |
| `src_line` | 原本テキスト内の行番号 |

**制約(重要)**:

- 検出したのは**1,028件**。原本のOCRが荒く(文字化け・表組みの崩れ・番号欠落)、肢の総数は実際にはこれより多い可能性が高い
  (既存の`data/oneliner.json`は2163問)。**網羅性は保証しない。**
- 正誤(○×)は、レイアウトの崩れで対応付けが不安定だったため`index.json`には**含めていない**。正誤は必ず
  `data/oneliner.json`等で確認する。
- `exam_refs`が空の肢は118件(出題履歴なし＝オリジナル問題または欄の取りこぼし)。
