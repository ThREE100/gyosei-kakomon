この問題は、在外国民（国外に住んでいて国内の市町村に住民登録がない日本国民）が最高裁判所裁判官の国民審査に投票できないのは憲法違反だと訴えた事件（在外邦人国民審査権訴訟）の最高裁大法廷判決を素材にしています。原告は、同じ争いについて2種類の訴え（本件地位確認の訴えと本件違法確認の訴え）を主位的・予備的に起こしましたが、判決はこの2つに異なる結論（一方は理由なしとして退け、他方は認容）を出しています。行政事件訴訟法が定める「公法上の法律関係に関する確認の訴え」（実質的当事者訴訟の一類型で、行政処分の取消しなどを求める抗告訴訟とは異なり、行政庁と私人の間の法律関係そのものの存否を裁判所に確認してもらう訴訟類型です）という訴訟類型の枠組みの中で、なぜ結論が分かれたのかを読み取れるかがこの問題の核心です。

### ア：どちらの訴えも「公法上の法律関係」に関する確認の訴え

行政事件訴訟法4条は「この法律において『当事者訴訟』とは、当事者間の法律関係を確認し又は形成する処分又は裁決に関する訴訟で法令の規定によりその法律関係の当事者の一方を被告とするもの及び公法上の法律関係に関する確認の訴えその他の公法上の法律関係に関する訴訟をいう。」と定めています。本文中、空欄アは3回登場し、いずれも「本件地位確認の訴えは〈ア〉に関する確認の訴えと解され」「このような訴えは〈ア〉に関する確認の訴えと解され」「〈ア〉に関する確認の訴えとして適法である」という形で、2つの訴えのどちらもが同じ訴訟類型に位置づけられていることを示しています。この訴訟類型が、行政事件訴訟法4条後段の「公法上の法律関係に関する確認の訴え」です。

**ここが分かりにくいポイント**：

「行政庁の公権力の行使に関する不服」（3）は、取消訴訟をはじめとする抗告訴訟（行政庁が行った処分そのものの効力を争う訴訟類型）の説明にあたる言葉であり、公法上の法律関係に関する確認の訴えとは別の訴訟類型です。本件の2つの訴えは、いずれも国民審査法上の「地位」や国の対応の「違法性」という法律関係の存否そのものを確認してもらう訴えであって、特定の行政処分の取消しを求めるものではないため、抗告訴訟ではなく当事者訴訟（公法上の法律関係に関する確認の訴え）に分類されます。

したがって、空欄アには「公法上の法律関係」が入ります。

### イ：地位確認の訴えは、理由がなく「棄却すべきもの」

本文は「国民審査法の規定により在外国民に審査権の行使が認められていると解することはできないから、本件地位確認の訴えに係る請求は理由がなく、〈イ〉である」と述べています。ここで大切なのは「請求は理由がなく」という言葉です。これは、訴え自体は適法に成立している（訴訟要件を満たしている）ものの、その中身（本案）を審理した結果、原告の言い分が認められないという場合に使われる表現です。

**ここが分かりにくいポイント**：

「却下すべきもの」（10）と混同しやすい箇所です。却下とは、訴えそのものが訴訟要件（訴えの提起の仕方が法律の定める条件を満たしているか）を欠いていて、そもそも中身の審理に入れない場合に使う言葉です。これに対し、本文は「請求は理由がなく」と、訴えの中身を審理したうえでの結論であることを明示しています。訴えの中身を審理したうえで原告の言い分が認められない場合に使うのは「棄却」です。

したがって、空欄イには「棄却すべきもの」が入ります。

### ウ：確認の訴えで確定するのは「確認判決」

本文は「当該訴えにおいて〈ウ〉が確定した場合、国会において、裁判所がした違憲である旨の判断が尊重されるものと解される」と述べています。本件違法確認の訴えは確認の訴え（確認訴訟）ですから、その訴えの結論として裁判所が下すのは、法律関係の存否や事実の存否を確認する「確認判決」です。

**ここが分かりにくいポイント**：

「取消判決」（18）や「形成判決」（16）は、いずれも別の訴訟類型で使われる判決類型です。取消判決は取消訴訟（抗告訴訟の一種）で処分を取り消す判決、形成判決は法律関係を新たに作り出したり変更したりする判決（会社の設立無効判決などが典型例です）を指します。本件違法確認の訴えは、処分の取消しを求めるものでも、新たな法律関係を作り出すものでもなく、国の対応が違法であるという法律関係の存否を確認してもらう訴えですから、確定するのは「確認判決」です。

したがって、空欄ウには「確認判決」が入ります。

### エ：紛争解決のために「有効適切」な手段であると認められる

本文は「結果的に上記の争いを解決するために〈エ〉な手段であると認められ、〈ア〉に関する確認の訴えとして適法である」と述べています。確認の訴えが適法と認められるためには、単に法律関係の確認を求めれば足りるわけではなく、その確認を求めることが現実の紛争解決にとって意味のある手段でなければならない（確認の利益と呼ばれる要件です）とされています。この判断枠組みでよく使われる定型的な言い回しが「紛争の解決のために有効適切な手段である」という表現です。

**ここが分かりにくいポイント**：

「簡易迅速」（8）や「効率的」（19）も、手続の速さや効率のよさを連想させる言葉として紛らわしいところです。しかし、確認の訴えが適法かどうかを判断する場面で問題にされているのは、手続にかかる時間や手間ではなく、その訴えを認めることが原告と被告の間の争いそのものを解決する道具として役に立つか（有効適切であるか）という点です。国会が裁判所の違憲判断を尊重するという仕組みと結び付けて、確認判決が争いの解決に現実に役立つ手段であることを述べている文脈なので、「有効適切」が適切です。

したがって、空欄エには「有効適切」が入ります。

### まとめ

- **ア＝公法上の法律関係**（行政事件訴訟法4条後段の当事者訴訟の一類型、2つの訴えに共通する訴訟類型）
- **イ＝棄却すべきもの**（本案審理のうえで請求に理由がないとされた本件地位確認の訴えの結論）
- **ウ＝確認判決**（確認の訴えの結論として裁判所が下す判決類型）
- **エ＝有効適切**（確認の訴えが適法と認められるための「確認の利益」の判断で使われる定型句）

同じ「アに関する確認の訴え」という枠組みに位置づけられながら、本件地位確認の訴えは棄却され、本件違法確認の訴えは認容されています。この違いは、前者が国民審査法の解釈上そもそも認められない権利の確認を求めていたのに対し、後者は国の対応の違法性（違憲な立法の不作為を理由とする違法性）の確認を求めるものであり、確認判決の確定によって国会の対応（法改正）を促すという現実的な紛争解決の効果が期待できる、という点にあります。

**正解：ア＝公法上の法律関係／イ＝棄却すべきもの／ウ＝確認判決／エ＝有効適切**

問題文を読んだ瞬間に「何を確認し、どの順番で結論にたどり着くか」を、空欄ごとに1パネルずつ示す解き方ガイド。ウ・エが問題にする「本件違法確認の訴えが適法かどうか」は、確認判決の確定という効果と、それが紛争解決に役立つかという2段階の判定が必要なため、エを実際の決定木（フローチャート）として描く。②の俯瞰ポスターとは別物で、②の内容は書き換えない。

Create a Japanese-language infographic, portrait layout, 1080x2600 pixels,

(2つの確認の訴え), but built as a set of 4 diagram-drawing panels (a "how to
sketch this fact pattern, in the right order" study reference) rather than
a quick-reference conclusion poster.

DIAGRAM-GUIDE REQUIREMENT (critical): Each panel's purpose is to show the
reader exactly what diagram they should draw on scratch paper while
reading this type of problem, AND the order in which they should check
conditions to get there — an isometric courthouse building, a ballot box
labeled 国民審査, a judge's gavel, a document stamped with 棄却 or 確認判決,
and a Diet building receiving a beam of light from a judgment document.
Where a blank requires checking multiple conditions in sequence before
reaching a conclusion, draw the panel's diagram as an actual decision
flowchart: diamond-shaped branch nodes with the condition written on them,
Yes/No（はい／いいえ）branch arrows, and a final conclusion node. Where a
blank is resolved by a single check, a labeled illustrative diagram is
sufficient — do not force a flowchart. Unlike a glanceable summary poster,

CRITICAL TEXT REQUIREMENT: All text must be rendered in standard Japanese

no Chinese-only characters, no Korean Hangul, no other non-Japanese

any characters. Within this English prompt text, use half-width
parentheses ( ) consistently — never open a parenthetical with a

BACKGROUND REQUIREMENT (critical): The entire canvas must be fully opaque
from edge to edge. Do NOT generate a transparent or alpha-channel
background under any circumstances, even if the output file format
supports transparency. Fill the full canvas — including every corner and
margin outside the panels — with a solid or illustrated opaque background
(the pale beige/gray tone used elsewhere in this style is a good
default). There must be no checkerboard pattern, no partially transparent
area, and no unpainted canvas edge anywhere in the final image.
